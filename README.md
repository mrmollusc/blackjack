# How to run?
1. Open blackjack.js and copy the file's content with Ctrl+C
2. Open a new tab in a browser (Google Chrome, MS Edge, Firefox, etc)
3. Right click, then press inspect or press F12 to open the inspector
4. Press the second box (console) at the top of the new interface and paste the code in the box with Ctrl+V. Some browsers may safeguard against pasting malicious code, so complete the requiremnt and then paste the code in.
5. Press enter and enjoy. Make sure not to press the 'Prevent this page... ... additional dialogue' option.
